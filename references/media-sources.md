# Curated trade-media sources by sector

Sector-specific publications that surface companies EARLIER than mainstream
databases. Herb's press source (web_mandate_prompt.md source 7) reads this file
when a mandate matches a sector below, and searches these outlets via
`site:<domain> "{query_term}"` — plus fetches the report/ecosystem pages
directly where marked 📊 (those list many companies at once).

To extend: add rows to an existing sector, or add a new `## <Sector>` block with
the same table shape. Keep domains bare (no https://). Herb matches a mandate to a
sector by keyword — so the sector heading keywords matter.
